
# **🛒 Madhav E-Commerce Sales Dashboard**

## **📊 Power BI Data Analytics Project**

## **📌 Project Overview**

This project focuses on analyzing e-commerce sales data using Microsoft Power BI. The dashboard helps understand sales performance, profit, quantity, customer orders, product categories, and payment methods.

## **🎯 Project Objectives**

- 📈 Analyze overall sales and profit.
- 🛍️ Understand product category and sub-category performance.
- 💳 Analyze customer payment methods.
- 📍 Compare sales across different states and cities.
- 📅 Track monthly sales and profit trends.
- 💡 Generate useful business insights for decision-making.

## **🛠️ Tools & Technologies**

- 📊 Microsoft Power BI
- 🧹 Power Query for data cleaning and transformation
- 🧮 DAX for calculations and measures
- 📉 Data Visualization
- 📁 CSV Dataset

## **📊 Dashboard Features**

- 💰 Total Amount
- 📦 Total Quantity
- 💹 Total Profit
- 🧾 Average Order Value (AOV)
- 📅 Monthly Profit Analysis
- 🛍️ Category and Sub-Category Analysis
- 💳 Payment Mode Analysis
- 📍 State-wise Sales Analysis
- 🎛️ Interactive Quarter Filters
